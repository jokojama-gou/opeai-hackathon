# 要求・差分・証拠のレビュー

このハッカソン向けの限定手順。[共通の使い方](../../../docs/development/aidd-lite/GUIDE.md)を確認し、現在の依頼と適用されるAGENTSを優先する。全skillの連続実行は要求しない。

## 手順と成果

- 原要求、正本、対象版、差分、実行結果を照合する。指摘は再現可能な失敗や根拠に基づき、件数や主観的な点数を成果にしない。製品変更ではPROJECT_CHECKSから関係する観点だけ選ぶ。
- 指摘は重要度（P1:主要な成果を損なう、P2:修正が必要、P3:任意改善）、箇所、失敗例、最小修正案、確認の限界を返す。問題がなければその旨と未検証範囲を返す。
- 独立レビューの依頼・許可がある場合だけGUIDEのreviewerへ委任する。主担当の自己確認を独立レビューと呼ばない。
- このskillは読み取り専用。修正も明示依頼されている場合、主担当がその範囲で修正し、変更した最終内容を再確認する。レビューへの合格はcommit・公開の許可ではない。

## 必要時に読む資料

- 製品の判断・共有・比較・デモに関係する場合：[プロジェクト固有の確認](../../../docs/development/aidd-lite/PROJECT_CHECKS.md)。
- 変更理由・由来を調べる場合：[出自](../../../docs/development/aidd-lite/PROVENANCE.md)。
