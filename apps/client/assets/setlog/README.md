Prompt direction: extract/redraw a front-facing lavender transparent cassette with ivory reels, sky, clouds and tiny stars, matching the supplied Setlog reference. No text, labels, buttons, screen frame or typography. The initial output baked a checkerboard into RGB pixels, so the second imagegen edit replaced the entire outside background with a flat pale mint `#F8FBF8`. This final image is opaque, not a transparent PNG.

Only reel overlays rotate while the real capture state is recording; reduced-motion mode disables the overlays. No simulated sound level is displayed. Fonts and original licenses are in the neighboring `fonts` directory.
