# 当日用：ひなた・ごうの声を登録する

2026-09-15。ログインせずに、自分の声をアプリ内へ保存する「登録準備」を実装しました。

## 操作

1. 最初の録音画面で「自分の声を登録する（ログイン不要）」を押します。
2. iOSアプリは **iPhoneのひなた**、Androidアプリは **Androidのごう** が自動で選ばれます。Web版だけ、どちらの名前か選びます。
3. 自分一人で15〜30秒を目安に話し、停止します。画面に読み上げ例があります。
4. 聞き直して「この声を登録用に保存する」を押します。録り直すときは削除ボタンで確認してから録音します。

メール・パスワード・アカウント作成は不要です。マイクの利用許可は必要です。ネイティブの録音は専用ビルドで使います。Expo Goでは画面のみ確認できます。Web録音は対応ブラウザのHTTPSまたはlocalhostが必要です。

## 保存と名前の意味

- 音声・名前は録音した端末内だけに保存します。ネイティブはアプリ領域、WebはそのブラウザのIndexedDBです。他端末へ同期しません。
- 録音終了から最大7日で利用期限が切れ、保存・再生できなくなります。期限切れの実ファイル/DB行は、次回の録音一覧読込・アプリ復帰時に削除します。アプリが停止中にOSへ削除を実行させる機能はありません。
- 期限前でも本人が画面から削除できます。ログインによる保護はなく、端末を操作できる人は確認・削除できます。
- 「ひなた」「ごう」は端末用の名前です。実際に話した人を証明するものではなく、共有許可にも使いません。
- 普通の会話録音と登録音声は分けています。登録音声は書き起こし・全社比較・旧共有APIの処理へ送れないようにしています。

## ElevenLabsとの接続状況

書き起こし用に推奨しているモデルは **ElevenLabs Scribe v2 (`scribe_v2`)** です。[モデルの説明](ASR_MODEL.md)に選定理由と実際の確認範囲があります。今回の登録操作では、このモデルを実行しません。

ElevenLabsの書き起こしAPIには、既にworkspaceへ登録された話者を照合する `use_speaker_library` があります。ただし、今回確認した公開API仕様では話者ライブラリへ音声を登録・削除するAPIを見つけられませんでした。「事前登録から自動で名前を付けるまで、このアプリだけで実装済み」とは言えません。[公式API](https://elevenlabs.io/docs/api-reference/speech-to-text/convert)、[機能追加の履歴](https://elevenlabs.io/docs/changelog/2026/6/15)。

現実装は **登録音声の準備まで** です。外部登録・外部照合・文字起こしの話者への実名付与は未接続で、音声合成のvoice cloning APIも使いません。次は話者ライブラリへの登録・削除方法、利用可能なworkspace、外部保存期限を確認してから接続します。

## 確認範囲

端末名の割当、登録音声の分離、保存条件、7日の期限を人工データで検証。Webの入口・2人の切替・戻る操作、iOS/Android/Webのローカル書き出しを確認しました。実機でのマイク録音・保存・再生と、実音声による外部話者照合は未確認です。[作業記録](../history/VOICE_ENROLLMENT_20260915.md)。
