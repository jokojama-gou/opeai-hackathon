# プロジェクト固有の確認索引

仕様の正本は[PRODUCT_CORE](../../product/PRODUCT_CORE.md)、ケースと音声条件は[VALIDATION](../VALIDATION.md)、価値の場面は[SCENARIOS_AND_SUCCESS](../../product/SCENARIOS_AND_SUCCESS.md)です。以下は点検観点であり、未決定の方式・合格値・製品仕様を採用するものではありません。関係する行だけ使います。

| 対象 | 根拠 | 確認すること |
|---|---|---|
| 会話の対応・統合 | D03/D05/D13、V01〜V04 | 話題が似ただけで同一会話としない。単独と統合を比較し欠落・重複・悪化・未判定も残す |
| 話者・端末・参加者 | D05〜D09/S03、V05〜V09 | 音声一致、端末所有、発言、正当な共有先を別々に確認する |
| 通常共有と派生情報 | D09/D17/S02、V06/V21 | Cの初発言より前をCの要約・検索・AI回答へ含めない。同じ区間に参加したA/Bまで拒否しない |
| 職場用共有 | D04/D11/D12/S04/O09、V11/V21 | 所属だけで通常記録を共有しない。職場用明示開始と通常共有の発言者条件を混同しない。詳細権限は未決定のまま扱う |
| 切断・取消・削除 | O05〜O07、V10/V13〜V20 | 未決定の境界や取消後・削除後の派生物処理を既定値で確定しない |
| 比較の再現性 | D13/O10、VALIDATION比較手順 | 対象版、入力条件、比較対象、正解、分母を対応させる。合格値未定なら探索。実行成功と優位性を区別する |
| 音声条件 | VALIDATION「音声の利用・処理条件」 | 現行条件ではAIは計画・コード整備、人は実音声処理。AIの分析対象は匿名ID・集計値。音声・文字起こし・特徴量をツール出力へ出さない |
| MVP・デモ | D14/O01/O10 | 候補比較と最終採用を分ける。実装済み・模擬・説明用・未検証を示す。大会条件が判断に必要なら根拠を確認し、創作しない |
| 2人の統合 | 開発手順「実装」「報告・引き継ぎ・再開」 | 対象版・変更範囲・受け渡す成果を共有し、相手の変更を保持して統合後も確認する |

実験限定の処理・保持条件は製品の処理場所を確定しません。条件が変わった場合は正本を読み直し、補助資料を新しい正本にしません。
