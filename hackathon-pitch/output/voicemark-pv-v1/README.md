## 素材と表現の区別

- 人物・カフェ：内蔵画像生成による架空の4枚。カメラ移動を付けた映像。人物の連続動作やリップシンクを動画モデルで生成したものではない。
- UI：採用仕様の説明用にコードで描いた画面。実アプリの画面録画ではなく、画面内にもコンセプトと表示。
- 音声：Windows内蔵の日本語音声による合成台詞・ナレーション。実在する人の録音や声の複製は使用しない。
- BGM・効果音：`render.py` で合成したオリジナル音源。声が入る区間はBGMを下げる。
- 書き出し：H.264/AAC、1920×1080、24fps、120秒。1280×720の合成画面を1080pに拡大してエンコード。
- [生成プロンプト](image-prompts.md)と[レンダラー](render.py)を同梱。生成方式は内蔵画像生成、ローカル動画合成。Runway等の外部動画サービスは使用していない。

## 製品の根拠

[MVP_SPEC](../../../docs/product/MVP_SPEC.md)のM01〜M06、M15、U02/U06/U17を中心に構成。複数入力は同一会話・共有許可範囲を明示し、AIは本人用かつ参照記録を選ぶ表現にする。集合時間は架空の台本で、実測性能・実際のASR/統合/AI結果とはしない。正式な製品機能の実装完了や公開・配布を主張しない。保持期限延長、自動録音、全履歴検索、相手への自動送信も示さない。

## 再生成と検証

このディレクトリで実行する。

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File ./make-voice.ps1
python ./render.py --preview
python ./render.py --render
python ./render.py --check
```

Python依存：Pillow、NumPy、OpenCV、imageio-ffmpeg。日本語書体と音声はWindows内蔵。音声エンジンがサンドボックス内で利用できない場合は通常のローカル権限で実行する。APIキー不要。

確認結果は [映像検査](checks/verification.json)、[音声検査](checks/audio.json)、[場面一覧](checks/contact-sheet.jpg)。映像検査は尺・解像度・fps・全編デコード・代表場面の読み出し、音声検査は23区間の尺内収録とピーク値。独立レビュー・スマホ実機確認・会場での音声試聴は未実施。
