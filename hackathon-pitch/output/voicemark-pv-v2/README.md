## 形式と素材

120秒、24fps、H.264/AAC、1920×1080。1280×720で合成後に1080pへ拡大。内蔵画像生成による静止画3枚（旧版のカフェ1枚＋翌朝2枚）、カメラ移動、説明用UIアニメーション、日本語合成音声22区間、コード合成のオリジナルBGMと効果音。

実アプリ録画や人物の連続動作を動画モデルで生成した映像ではない。製品の実装状況・実機・ASR/統合精度の証拠にはしない。Voicemark、2分、メタ的停止というユーザー指定と、M01〜M06/M15の説明範囲は維持する。
